# Безопасность и границы проверки

Эта редакция подготовлена из [версии Suveren под MIT](https://github.com/maratmu1988-afk/suveren). Исходная лицензия сохранена. Код проверен статически перед публикацией; полный аудит зависимостей и работа на всех сайтах этим не подтверждаются.

## Доступы

- Утилита не запрашивает токен GitHub, пароли, доступ к аккаунту или права администратора.
- Обычная проверка делает сетевые запросы к указанному сайту, DNS/WHOIS и публичным источникам данных. Списки блокировок и санкций кэшируются локально; HTML и JSON отчёты пишутся в выбранную папку.
- В репозитории оставлен только CI с `contents: read`. Workflow с `contents: write`, автоматическая публикация `.exe` и ежедневные сетевые проверки удалены.
- Windows-скрипт, который при первом запуске автоматически устанавливал зависимости, удалён. Установка Python-пакета остаётся явным действием пользователя.

## Ограничения

- HTTP-клиент следует редиректам. Не запускайте сканирование непроверенных адресов в сети с доступом к внутренним сервисам; инструмент не является защищённым публичным сканер-сервисом.
- Режим `--browser` запускает JavaScript проверяемого сайта в локальном браузере. Используйте его только для сайтов, которым доверяете, или в изолированной среде.
- При ошибке TLS-сертификата код может повторить чтение сайта без проверки сертификата для анализа содержимого; это не подтверждает подлинность сайта.
- Проверки 152-ФЗ и других требований эвристические. Отчёт показывает возможные проблемы и требует ручной юридической и технической проверки.
- Зависимости Python заданы диапазонами минимальных версий, без lock-файла; при установке проверяйте актуальные пакеты и источник загрузки.

Код не содержит фоновой отправки отчётов автору или скрытой телеметрии по результатам статической проверки этой версии. Это утверждение не распространяется на будущие обновления или внешние зависимости.
